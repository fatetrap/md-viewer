# Welcome to Markdown Viewer! 🚀

A beautiful, interactive, and glassmorphic Markdown viewer built with modern web technologies.

## Features ✨

*   **Drag & Drop**: Easily drop your `.md` files directly onto the page.
*   **Syntax Highlighting**: Beautiful code blocks powered by *Highlight.js*.
*   **Dark Mode**: Protect your eyes with a stunning dark theme.
*   **Secure**: Content is sanitized using `DOMPurify` to prevent XSS.

### Interactive Elements

Try interacting with links, checking out the typography, and noticing the subtle glassmorphism effects in the UI!
